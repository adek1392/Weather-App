# 🌤 Weather App

Prosta aplikacja pogodowa stworzona w czystym JavaScript, HTML i SCSS,
która pobiera aktualne dane pogodowe z [WeatherAPI.com](https://www.weatherapi.com/).


## 🔗 Demo

Zobacz aplikację na żywo: [weather-app.vercel.app](https://weather-app-weld-five.vercel.app/)

## ✨ Funkcje

- Wyszukiwanie pogody po nazwie miasta
- Wyświetlanie temperatury, wilgotności, wiatru i ostatniej aktualizacji
- Ikona stanu pogody
- Obsługa błędów (np. błędna nazwa miasta)
- Kompilacja SCSS → CSS
- Ukryty klucz API (serverless backend)

## 🛠 Technologie

- JavaScript (vanilla)
- SCSS
- Axios
- [WeatherAPI](https://www.weatherapi.com/)
- Vercel
